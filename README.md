# Stefanus Foukaridis - Portfolio

Professional portfolio website for Stefanus Foukaridis, a Principal Full-Stack Engineer with over 18 years of experience in fintech, education, telecoms, and cloud platforms.

## 🚀 Overview

This modern, responsive single-page application showcases my professional journey, technical expertise, and featured projects. Built with React and Tailwind CSS, it delivers a premium user experience with smooth navigation and dynamic content.

## 🛠️ Tech Stack

- **Frontend:** React 18
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Build Tool:** Create React App

## ✨ Features

- **Responsive Design:** Fully fluid layout optimized for mobile, tablet, and desktop devices.
- **Dynamic content:** Years of experience and copyright dates are automatically calculated based on the current date.
- **Interactive UI:**
  - Sticky navigation with backdrop blur
  - Mobile responsive menu
  - Hover effects on project and skill cards
  - Smooth scrolling for internal links
- **Project Showcase:** Detailed view of key projects with tech stacks and highlights.

## 📦 Getting Started

### Prerequisites

- Node.js (v14 or higher recommended)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd foukaridis
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:
```bash
npm start
```
The application will open at [http://localhost:3000](http://localhost:3000).

### Production Build

Create an optimized production build:
```bash
npm run build
```
The build artifacts will be stored in the `build/` directory.
